```text
bun run manifold registry import [flags]
```

Mints registry rows for every live AniList manga entry and records list status with `origin: migration` and `appliedRemotely: true`. **No ops are enqueued** — AniList already holds that state.

Dry-run until `--apply`. The dry run reports how many live AniList entries are importable without changing the registry.

## Flags

| Flag | Default | Notes |
| --- | --- | --- |
| `--anilist-token` | env | Live AniList list |
| `--apply` | `false` | Mint rows and record list state |
| `--api-token` | env | `MANIFOLD_TOKEN` / `ALCHEMY_SECRET_MANIFOLD_TOKEN` |
| `--api-origin` | env / `https://manifold.jfa.dev/api` | Personal API origin |

## Usage

```text
bun run manifold reconcile diff     # optional: see drift first
bun run manifold registry import
bun run manifold registry import --apply
```

Typical pairing: [reconcile diff](/cli/reconcile-diff/) to inspect, then `registry import` to align.
