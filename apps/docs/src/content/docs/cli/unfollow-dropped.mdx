```text
bun run manifold unfollow-dropped [flags]
```

Also available as `manifold mangadex unfollow-dropped` and alias `manifold mangadex-unfollow`.

Unchecks **Follow** on MangaDex for titles in the selected reading status. Reading status itself is unchanged — only the follow relationship is removed. Dry-run until `--apply`.

## Flags

### `--status <statuses>`

Select the current MangaDex reading status or statuses to unfollow. Pass a
comma-separated list. Valid statuses include `reading`, `re_reading`,
`on_hold`, `plan_to_read`, `completed`, and `dropped`.

- Default: `dropped`

Example:

```text
bun run manifold unfollow-dropped --status dropped,on_hold
```

### `--apply`

Remove the Follow relationship for matching titles. Without this flag, the
command reports the titles but leaves them followed.

- Default: `false`

Example:

```text
bun run manifold unfollow-dropped --apply
```

### `--mangadex-client-id <id>`

OAuth client ID for the MangaDex password grant. Falls back to
`MANGADEX_CLIENT_ID` or `ALCHEMY_SECRET_MANGADEX_CLIENT_ID`.

Example:

```text
bun run manifold unfollow-dropped --mangadex-client-id "$MANGADEX_CLIENT_ID"
```

### `--mangadex-client-secret <secret>`

OAuth client secret for the MangaDex password grant. Falls back to
`MANGADEX_CLIENT_SECRET` or `ALCHEMY_SECRET_MANGADEX_CLIENT_SECRET`.

Example:

```text
bun run manifold unfollow-dropped --mangadex-client-secret "$MANGADEX_CLIENT_SECRET"
```

### `--mangadex-username <username>`

MangaDex account username for the password grant. Falls back to
`MANGADEX_USERNAME` or `ALCHEMY_SECRET_MANGADEX_USERNAME`.

Example:

```text
bun run manifold unfollow-dropped --mangadex-username "$MANGADEX_USERNAME"
```

### `--mangadex-password <password>`

MangaDex account password for the password grant. Falls back to
`MANGADEX_PASSWORD` or `ALCHEMY_SECRET_MANGADEX_PASSWORD`.

Example:

```text
bun run manifold unfollow-dropped --mangadex-password "$MANGADEX_PASSWORD"
```

## Usage

```text
bun run manifold unfollow-dropped
bun run manifold unfollow-dropped --status dropped,on_hold
bun run manifold unfollow-dropped --apply
```

The report intersects the status list with your currently followed set, so already-unfollowed titles do not appear as work items.
