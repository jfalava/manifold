```text
bun run manifold ops pending [flags]
```

Read-only triage for the personal API op log. Prints every non-completed op (up to 200 per state) with id, kind, origin, attempt count, and last error.

## Flags

| Flag           | Default                              | Notes                                              |
| -------------- | ------------------------------------ | -------------------------------------------------- |
| `--api-token`  | env                                  | `MANIFOLD_TOKEN` / `ALCHEMY_SECRET_MANIFOLD_TOKEN` |
| `--api-origin` | env / `https://manifold.jfa.dev/api` | Personal API origin                                |

## Usage

```text
bun run manifold ops pending
```

Ops auto-retry up to 5 attempts before landing in `blocked`. Use [retry](/cli/ops/retry/) to re-queue one.

Remember where ops execute: `mangadex:*` drains on the Worker; `anilist:*` waits for your device.
