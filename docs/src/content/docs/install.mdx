## Reading providers

Add the Inkdex repository in Paperback under **Settings → Extensions → Add
repository**:

```text
https://inkdex.github.io/extensions/0.9/stable
```

Install the native **MangaDex** and **Comix** extensions from it. They own
chapter discovery, updates, Cloudflare handling, and reading.

## ManifoldTracker

Add the Manifold repository:

```text
https://manifold.jfa.dev/paperback/extensions/0.9/stable/
```

Install **ManifoldTracker**, open its settings, and set the personal API token
from `MANIFOLD_TOKEN`. The token stays in Paperback secure state.

## Import the library

Generate a source-free `.pas5` backup, using a current Paperback export as the
base when migrating an existing library:

```text
bun run manifold migrate al2pas5 --apply --base ./Paperback-Backup.pas5
```

Restore the generated archive in Paperback. Each eligible library entry is
attached to:

- its registry-linked native MangaDex and/or Comix source;
- ManifoldTracker, using the canonical registry UUID.

Entries without a canonical UUID or a linked native content provider are not
created. Existing base entries are enriched when they can be matched; obsolete
ManifoldSource attachments and providerless remnants are removed.

<Aside type="caution" title="Keep the original backup">
  Restoring a `.pas5` archive may replace the on-device library. Keep the
  original export until the migrated library has been checked.
</Aside>

## How updates flow

Paperback asks the native provider for chapters. ManifoldTracker receives the
provider's exact source and manga IDs, records the read against the canonical
entry, and fans progress out through the Durable Object outbox.

## Surfaces

| Surface       | URL                                                         |
| ------------- | ----------------------------------------------------------- |
| Documentation | `https://manifold.jfa.dev/`                                 |
| Sync API      | `https://manifold.jfa.dev/api/v1/`                          |
| Health        | `https://manifold.jfa.dev/api/health`                       |
| Repository    | `https://manifold.jfa.dev/paperback/extensions/0.9/stable/` |

```text
MangaDex / Comix → Paperback library entry → ManifoldTracker
                 → POST /api/v1/entries/:entryId/read
                 → Durable Object outbox → linked trackers/providers
```
