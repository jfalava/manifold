## Reading providers

Add the Inkdex repository in Paperback under **Settings → Extensions → Add
repository**:

```text
https://inkdex.github.io/extensions/0.9/stable
```

Install the native **MangaDex** and **Comix** extensions from it. They own
chapter discovery, updates, Cloudflare handling, and reading.

## MANIFOLD

Add a Manifold repository (stable is the default install):

```text
https://manifold.jfa.dev/paperback/extensions/0.9/stable/
```

For the current-tree beta channel (separate extension id, safe beside stable):

```text
https://manifold.jfa.dev/paperback/extensions/0.9/beta/
```

| Channel | Repository URL                                                   | Extension id    |
| ------- | ---------------------------------------------------------------- | --------------- |
| Stable  | `https://manifold.jfa.dev/paperback/extensions/0.9/stable/`      | `MANIFOLD`      |
| Beta    | `https://manifold.jfa.dev/paperback/extensions/0.9/beta/`        | `MANIFOLD-beta` |

Install **MANIFOLD** (or **MANIFOLD beta**), open its settings, and choose
**Login with GitHub**. Paperback completes the PKCE exchange and stores only
the Manifold session in secure state; no `MANIFOLD_TOKEN` is required.

The CLI uses the same GitHub OAuth App:

```sh
manifold login manifold
```

Open the printed URL in a browser. The session is stored in the OS keychain and
refreshes automatically for later registry and maintenance commands.

## Import the library

Generate a source-free `.pas5` backup, using a current Paperback export as the
base when migrating an existing library:

```sh
manifold anilist create pas5 --apply --base ./Paperback-Backup.pas5
```

Restore the generated archive in Paperback. Each eligible library entry is
attached to:

- its registry-linked native MangaDex and/or Comix source;
- MANIFOLD, using the canonical registry UUID.

Follow the [verified import procedure](/cli/anilist/create-pas5/#verified-restore-procedure-start-with-an-empty-database):
back up first, use an empty database and an archive with uppercase internal UUIDs,
then run Paperback's **database repair before opening imported titles**.
Repair alone did not fix every title in an existing database. Check saved state
after leaving and reopening titles before discarding the original backup.

Entries without a canonical UUID or a linked native content provider are not
created. Existing base entries are enriched when they can be matched; obsolete
ManifoldSource attachments and providerless remnants are removed.

<Aside type="caution" title="Keep the original backup">
  Restoring a `.pas5` archive may replace the on-device library. Keep the original export until the
  migrated library has been checked.
</Aside>

## How updates flow

Paperback asks the native provider for chapters. MANIFOLD receives the
provider's exact source and manga IDs, records the read against the canonical
entry, and fans progress out through the Durable Object outbox.
