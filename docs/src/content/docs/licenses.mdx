## Attributions

### Inkdex

The MangaDex and AniList integrations and the core of the `MANIFOLD` tracker
extension are modified versions of Inkdex's GPL-3.0-or-later Paperback
extensions:

- [Inkdex General Extensions](https://github.com/inkdex/general-extensions),
  branch `0.9/stable`, `src/MangaDex/`
- [Inkdex Tracker Extensions](https://github.com/inkdex/tracker-extensions),
  branch `0.9/stable`, `src/AniList/`

The derived files are `packages/mangadex/src/**`,
`packages/paperback-runtime/src/anilist-graphql.ts`, and the
`tracker/src/MANIFOLD` `main.ts`, `managed-collections.ts`, `pbconfig.ts` and
`read-queue.ts` files. They keep the Inkdex copyright notice next to a dated
Manifold modification notice. The generated `MANIFOLD` and `MANIFOLD-beta`
bundles combine these files and are distributed under GPL-3.0-or-later.

### CLI releases

The CLI source is MIT, but each released `manifold` executable also bundles
the GPL-derived MangaDex code, so the executable as a whole is conveyed under
GPL-3.0-or-later. Every release archive ships `LICENSE`, `LICENSE-MIT`,
`ATTRIBUTIONS.md`, and a `THIRD-PARTY-NOTICES.md` listing each bundled package
with its license text and a link to the tagged source.
