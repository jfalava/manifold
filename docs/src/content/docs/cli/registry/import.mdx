```text
bun run manifold registry import [flags]
```

Mints registry rows for every live AniList manga entry and records list status with `origin: migration` and `appliedRemotely: true`. **No ops are enqueued** — AniList already holds that state.

Dry-run until `--apply`. The dry run reports how many live AniList entries are importable without changing the registry.

## Flags

### `--anilist-token <token>`

AniList access token for the live manga list. Resolve order: flag → `MANIFOLD_ANILIST_TOKEN` → `anilist login` keychain.

Example:

```text
bun run manifold anilist login
bun run manifold registry import
```

### `--apply`

Mint registry rows and record the live AniList list state. Without this flag,
the command reports how many entries can be imported without changing the
registry.

- Default: `false`

Example:

```text
bun run manifold registry import --apply
```

### `--api-token <token>`

Personal API token used to write the registry. Falls back to `MANIFOLD_TOKEN`.

Example:

```text
bun run manifold registry import --api-token "$MANIFOLD_TOKEN"
```

### `--api-origin <url>`

Personal API origin containing the registry.

- Default: `https://manifold.jfa.dev/api` (or `MANIFOLD_API_ORIGIN`)

Example:

```text
bun run manifold registry import --api-origin https://manifold.example/api
```

## Usage

```text
bun run manifold reconcile diff     # optional: see drift first
bun run manifold registry import
bun run manifold registry import --apply
```

Typical pairing: [reconcile diff](/cli/reconcile-diff/) to inspect, then `registry import` to align.
