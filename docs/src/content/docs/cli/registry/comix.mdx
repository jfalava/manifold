```text
bun run manifold registry comix [flags]
```

Backfills missing Comix `hid` provider links. comix.to's JSON API is HMAC-signed and Cloudflare-gated, so the CLI does **not** replay cookies through `fetch`. It captures `/browse?keyword=` inside a local Chrome WebView (same approach as the Paperback source) and stores the jar in `Bun.secrets` until `cf_clearance` expires.

Dry-run until `--apply`.

## Flags

### `--apply`

Write matched Comix provider links to the registry. Without this flag, the
command only reports the links it finds.

- Default: `false`

Example:

```text
bun run manifold registry comix --apply
```

### `--limit <n>`

Attempt at most `n` registry rows that do not already have a Comix link.

- Default: all rows without a Comix link

Example:

```text
bun run manifold registry comix --limit 25
```

### `--status <statuses>`

Filter rows by their reading status before processing them. Use `auto` for all
statuses, or pass a comma-separated list such as `reading,completed`. As with
the [MangaDex prefill](/cli/registry/mangadex/), `reading` includes
`re_reading`.

- Default: `auto`

Example:

```text
bun run manifold registry comix --status reading,completed
```

### `--chrome-cdp-url <url>`

Attach to an already-running Chrome DevTools WebSocket instead of
auto-launching a dedicated browser. The value must look like
`ws://127.0.0.1:9222/...`. Falls back to `MANIFOLD_COMIX_CHROME_CDP_URL`.

Example:

```text
bun run manifold registry comix --chrome-cdp-url "ws://127.0.0.1:9222/devtools/browser/..."
```

### `--refresh-session`

Discard the stored OS-keychain cookie jar and harvest a new session in the
Chrome view.

- Default: `false`

Example:

```text
bun run manifold registry comix --refresh-session
```

### `--cf-clearance <value>`

Seed the browser view with a `cf_clearance` cookie. This is optional and is
used only inside the view; it falls back to `MANIFOLD_COMIX_CF_CLEARANCE`.

Example:

```text
bun run manifold registry comix --cf-clearance "$MANIFOLD_COMIX_CF_CLEARANCE"
```

### `--session <value>`

Seed the browser view with a session cookie. It falls back to `MANIFOLD_COMIX_SESSION`.

Example:

```text
bun run manifold registry comix --session "$MANIFOLD_COMIX_SESSION"
```

### `--cookies <header>`

Seed the browser view with a complete `Cookie` header. This takes precedence
over the individual `--cf-clearance` and `--session` flags, and falls back to
`MANIFOLD_COMIX_COOKIES`.

Example:

```text
bun run manifold registry comix --cookies "cf_clearance=...; session=..."
```

### `--api-token <token>`

Personal API token used to read and update registry rows. Falls back to
`MANIFOLD_TOKEN`.

Example:

```text
bun run manifold registry comix --api-token "$MANIFOLD_TOKEN"
```

### `--api-origin <url>`

Personal API origin containing the registry.

- Default: `https://manifold.jfa.dev/api` (or `MANIFOLD_API_ORIGIN`)

Example:

```text
bun run manifold registry comix --api-origin https://manifold.example/api
```

### `--anilist-token <token>`

Optional AniList access token used to search with English and romaji aliases.
Falls back to `MANIFOLD_ANILIST_TOKEN`.

Example:

```text
bun run manifold registry comix --anilist-token "$MANIFOLD_ANILIST_TOKEN"
```

## Chrome / Cloudflare

Turnstile needs a real window. The CLI launches headed Chrome with a dedicated `~/.manifold/comix-chrome` profile because Chrome 136+ ignores `--remote-debugging-port` on the default profile. Solve the check in that window, then press Enter if prompted. After three challenges the run circuit-breaks.

Do **not** tell the CLI to attach by opening plain Chrome with `--remote-debugging-port=9222` on the default profile — that port never opens on Chrome 136+.

## Usage

```text
bun run manifold registry comix
bun run manifold registry comix --apply
bun run manifold registry comix --refresh-session --apply
```

Requires a local Chrome/Chromium/Edge/Brave install. Search titles use registry + AniList aliases (capped per search).
