```text
bun run manifold anilist wipe manga [flags]
```

**Destructive.** Port of the AniList manga bulk-delete approach: scans your
AniList profile, then deletes **all** manga list entries and **all**
manga-related activities (list updates and text posts matching manga keywords).
Anime is never touched.

The command scans and reports what it would delete by default. `--apply` enables deletion and still prompts for confirmation. Pass `--yes` with `--apply` only when you intend to skip that prompt.

## Flags

### `--apply`

Permanently delete the scanned AniList manga list entries and manga-related
activities. Without this flag, the command only scans and reports the data.

- Default: `false`

Example:

```text
bun run manifold anilist wipe manga --apply
```

### `--yes`

Skip the interactive confirmation prompt. This flag has an effect only when
combined with `--apply`.

- Default: `false`

Example:

```text
bun run manifold anilist wipe manga --apply --yes
```

### `--anilist-token <token>`

Optional AniList access token override. Resolve order: flag → `MANIFOLD_ANILIST_TOKEN` → `login anilist` keychain.

Example:

```text
bun run manifold login anilist
bun run manifold anilist wipe manga
```

## Usage

```text
bun run manifold anilist wipe manga
bun run manifold anilist wipe manga --apply
bun run manifold anilist wipe manga --apply --yes
```

An empty manga list exits cleanly without deleting anything.

<Aside type="danger" title="Irreversible">
  This permanently removes manga list state and activity history on AniList. Prefer exporting or
  migrating first if you still need the data.
</Aside>
