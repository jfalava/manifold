title: login
description: Authorize upstream providers and store credentials in the OS keychain.
sidebar:
  order: 1
  label: Overview
---

```text
bun run manifold login <provider> [flags]
```

Top-level authentication for CLI work. Each provider uses its own OAuth client
and keychain entry — separate from the admin/API Durable Object tokens.

| Provider | Command | Keychain |
| -------- | ------- | -------- |
| AniList | [`login anilist`](/cli/login/anilist) | `manifold` / `anilist-session` |
| MyAnimeList | [`login mal`](/cli/login/mal) | `manifold` / `mal-session` |

MangaDex CLI flows still use password-grant env vars or `MANIFOLD_MANGADEX_TOKEN`
(no interactive `login mangadex` yet).

```text
bun run manifold login anilist
bun run manifold login mal
```
