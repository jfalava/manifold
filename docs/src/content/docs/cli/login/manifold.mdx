```sh
manifold login manifold [flags]
```

Device-code sign-in ([RFC 8628](https://www.rfc-editor.org/rfc/rfc8628))
against the Manifold API. The CLI shows a short code; you approve it in any
browser by signing in with the allowlisted GitHub account. The CLI never sees
the GitHub client secret, binds no local port, and asks you to paste nothing, so
headless hosts sign in the same way as desktops. Primary consumers: registry,
ops, reconcile, and other commands that call the personal API.

## Setup

No separate OAuth client registration is required. The CLI uses the built-in
`manifold-cli` client.

Optional:

```text
MANIFOLD_API_ORIGIN=https://manifold.jfa.dev/api
```

## Flags

### `--api-origin <url>`

Manifold API origin. Falls back to `MANIFOLD_API_ORIGIN`, then
`https://manifold.jfa.dev/api`.

## Usage

```sh
manifold login manifold
```

The command prints a code such as `BCDF-GHJK` and a link to
`https://manifold.jfa.dev/device?code=BCDF-GHJK`. Open it on any device, check
that the page shows the same code, and choose **Approve** (then sign in with
GitHub) or **Deny**. On a TTY, **`c`** copies the link, **`o`** opens it where a
local browser is available, and **Esc** or **Ctrl+C** cancels. The code expires
after ten minutes.

Approve only codes you started yourself: approving signs the waiting CLI in as
you. A GitHub account outside the allowlist is refused and the CLI keeps waiting
until the code expires.

After approval, the CLI receives access + refresh tokens on its next poll and stores the
session in the OS keychain under `manifold` / `manifold-session`. Rotated
refresh tokens are saved on later API use.

Long-running commands reread the keychain before refreshing an expired or rejected
access token. If another CLI process already rotated the session, the command uses
the newer credentials. A failed refresh checks storage once more to cover a
rotation during the request; it never retries the same rejected refresh token.
If storage has no usable replacement, run `manifold login manifold` again.
Registry reports retain successful links and failed rows can be retried with
`--resume` without raising discovery limits.

Downstream API credentials resolve as: **flag → `MANIFOLD_TOKEN` → keychain**.
`MANIFOLD_TOKEN` remains a break-glass override without refresh.
