`manifold` lives in `cli` (`@manifold/cli`). Run it from the repo root:

```text
bun run manifold <subcommand> [flags]
```

## Configuration

Remote-touching commands resolve credentials in this order: **flag →
`MANIFOLD_*` env** (from `cli/.env` or the process environment).

### `--api-token <token>`

Personal API token for `ops`, `reconcile`, and `registry` commands. Falls back
to `MANIFOLD_TOKEN`.

Example:

```text
bun run manifold ops pending --api-token "$MANIFOLD_TOKEN"
```

### `--api-origin <url>`

Personal API origin for `ops`, `reconcile`, and `registry` requests. Falls back
to `MANIFOLD_API_ORIGIN`.

- Default: `https://manifold.jfa.dev/api`

Example:

```text
bun run manifold reconcile diff --api-origin https://manifold.example/api
```

### `--anilist-token <token>`

AniList access token for migration, reconcile, and registry commands. Falls
back to `MANIFOLD_ANILIST_TOKEN`.

Example:

```text
bun run manifold registry import --anilist-token "$MANIFOLD_ANILIST_TOKEN"
```

`migrate anilist-to-mangadex`, `stale-status`, and `unfollow-dropped` require
all four MangaDex credentials.

### `--mangadex-client-id <id>`

OAuth client ID for the MangaDex password grant. Falls back to
`MANIFOLD_MANGADEX_CLIENT_ID`.

Example:

```text
bun run manifold stale-status --mangadex-client-id "$MANIFOLD_MANGADEX_CLIENT_ID"
```

### `--mangadex-client-secret <secret>`

OAuth client secret for the MangaDex password grant. Falls back to
`MANIFOLD_MANGADEX_CLIENT_SECRET`.

Example:

```text
bun run manifold stale-status --mangadex-client-secret "$MANIFOLD_MANGADEX_CLIENT_SECRET"
```

### `--mangadex-username <username>`

MangaDex account username for the password grant. Falls back to
`MANIFOLD_MANGADEX_USERNAME`.

Example:

```text
bun run manifold stale-status --mangadex-username "$MANIFOLD_MANGADEX_USERNAME"
```

### `--mangadex-password <password>`

MangaDex account password for the password grant. Falls back to
`MANIFOLD_MANGADEX_PASSWORD`.

Example:

```text
bun run manifold stale-status --mangadex-password "$MANIFOLD_MANGADEX_PASSWORD"
```

### MangaDex credentials together

Pass all four flags when credentials are not available through the
environment:

Example:

```text
bun run manifold stale-status \
  --mangadex-client-id "$MANIFOLD_MANGADEX_CLIENT_ID" \
  --mangadex-client-secret "$MANIFOLD_MANGADEX_CLIENT_SECRET" \
  --mangadex-username "$MANIFOLD_MANGADEX_USERNAME" \
  --mangadex-password "$MANIFOLD_MANGADEX_PASSWORD"
```

AniList writes always run on your machine — AniList blocks Cloudflare Worker egress IPs, which is also why `anilist:*` ops drain on the device rather than the Worker.

## Dry-run defaults

Every command that changes remote state is **dry-run until `--apply`**. `migrate wipe-al --apply` also requires interactive confirmation unless `--yes` is present.

## Exit codes

Human-readable tables and summaries go to stdout. Non-zero exit means failure — usually an upstream HTTP error (AniList rate limits: expect ~2.5 s spacing and 429 backoff) or a missing token.
