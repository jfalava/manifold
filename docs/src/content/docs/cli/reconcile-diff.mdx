```text
bun run manifold reconcile diff [flags]
```

**Read-only.** Walks every live AniList manga entry, maps statuses into registry vocabulary, and prints `NOT IN REGISTRY` / `DRIFT` lines plus a summary.

## Flags

### `--anilist-token <token>`

Required AniList access token used to fetch the live manga list. Falls back to
`MANIFOLD_ANILIST_TOKEN`.

Example:

```text
bun run manifold reconcile diff --anilist-token "$MANIFOLD_ANILIST_TOKEN"
```

### `--api-token <token>`

Personal API token used to read the registry. Falls back to `MANIFOLD_TOKEN`.

Example:

```text
bun run manifold reconcile diff --api-token "$MANIFOLD_TOKEN"
```

### `--api-origin <url>`

Personal API origin containing the registry.

- Default: `https://manifold.jfa.dev/api` (or `MANIFOLD_API_ORIGIN`)

Example:

```text
bun run manifold reconcile diff --api-origin https://manifold.example/api
```

## Usage

```text
bun run manifold reconcile diff
```

When AniList was edited directly on anilist.co, the registry projection silently disagrees. Fix drift with [registry import](/cli/registry/import/) — that command records live status with `appliedRemotely: true` and does **not** enqueue ops.
