```text
bun run manifold mal <command> [flags]
```

Provider ops for the signed-in MyAnimeList account. Authorize first with
[`login mal`](/cli/login/mal). MAL is a downstream status backup only — never
canonical authority.

| Command | Purpose |
| ------- | ------- |
| [`wipe manga`](/cli/mal/wipe-manga) | Delete every MAL manga list entry (anime untouched) |

```text
bun run manifold login mal
bun run manifold mal wipe manga
bun run manifold mal wipe manga --apply --backup-paused
```
