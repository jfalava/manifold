```sh
manifold upgrade
```

Self-update for the **compiled** `manifold` binary. Release tags are `cli-vX.Y.Z`
and must match `cli/package.json` `version`. Assets come from GitHub Releases
(`manifold-cli-<os>-<arch>.zip` + `.sha256`).

## Requirements

- Must run from the compiled binary (not `bun index.ts` / source).
- Supported platforms: Linux x64/arm64, macOS arm64, Windows x64.

## Usage

```text
manifold upgrade
```

When already current:

```text
manifold 0.1.0 is already up to date.
```
