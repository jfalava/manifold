## Tooling

- Bun workspaces
- TypeScript project references
- Effect (see root `package.json` catalogs)
- Alchemy for Cloudflare infrastructure as code
- Vitest for deploy-free unit tests

Secrets for local CLI work live in `cli/.env` (see `cli/.env.example`). Deploy
secrets and the catalog channel live in `iac/.env`.

## Deploy channel (`ENV`)

`plan`, `deploy`, and `build:catalog` read `ENV` from the process environment
or `iac/.env` (process wins):

| `ENV` value         | Catalog path                         | Tracker id       |
| ------------------- | ------------------------------------ | ---------------- |
| `manifold-stable`   | `/paperback/extensions/0.9/stable`   | `MANIFOLD`       |
| `manifold-beta`     | `/paperback/extensions/0.9/beta`     | `MANIFOLD-beta`  |

Only the selected channel is restaged. The other channel's previously deployed
assets stay on the Worker until you deploy that channel. Set `ENV` in
`iac/.env` (see `iac/.env.example`) or override for one run:

```sh
ENV=manifold-stable bun run deploy -- --yes
ENV=manifold-beta bun run deploy -- --yes
```

## Commands

```sh
bun install
bun run typecheck
bun run test
bun run test:oauth
bun run test:canonical
bun run test:paperback
bun run build:docs
bun run plan
bun run deploy
bun run manifold <subcommand>
```

`plan` and `deploy` always rebuild the Paperback catalog first for the active
`ENV` channel. Review the Alchemy plan before deploying. Non-interactive
deploys:

```sh
bun run deploy -- --yes
```

There is no Wrangler deploy script in this repository — Alchemy owns production.

CLI migrations and maintenance are documented under [CLI](/cli/).
